📋 قائمة فحص نهائية

  
احصل على بيانات Firebase Web Config من Firebase Console ← Project Settings ← General ← Your apps ← Web app.

  
احصل على VAPID Public Key من Cloud Messaging ← Web Push certificates ← Generate key pair.

  
استبدل القيم في index.html (متغير FCM_CONFIG و FCM_VAPID_KEY) وفي firebase-messaging-sw.js (داخل firebase.initializeApp).

  
ارفع التحديثات إلى Netlify وانتظر اكتمال النشر.

  
افتح هذه الصفحة من الموقع المنشور، املأ القيم نفسها، اضغط ابدأ كل الفحوصات.

  
إذا ظهر التوكن، جرّب إرسال اختبار لنفسي ضع بريدك المسجّل.
